# FastAPI To-Do App

A simple and lightweight RESTful To-Do application built with [FastAPI](https://fastapi.tiangolo.com/).

## Features

- **Create Tasks**: Add new to-do items with details like title and status.
- **Read Tasks**: Fetch all tasks or view specific task details.
- **Update Tasks**: Modify existing task information or mark them as completed.
- **Delete Tasks**: Remove unwanted tasks.
- **Interactive API Docs**: Built-in Swagger UI for quick API testing.

---

## Tech Stack

- **Framework**: FastAPI
- **Language**: Python 3.8+
- **Server**: Uvicorn
